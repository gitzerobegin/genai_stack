# Some lock-in is a good trade
Post: Post 23 · Week 12 · Which lock-in is acceptable
Caption: Lock-in to a product is usually tolerable; lock-in of the firm's own records is not. Classify each layer once, record it in the exit plan, and review it when ownership changes. Generic: no vendor names.
Source: Synthesis IX.4
