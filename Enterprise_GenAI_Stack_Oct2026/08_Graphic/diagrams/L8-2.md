# L8 decision tree: ingesting public web and enterprise documents
Caption: Nothing is ingested from an unregistered source; public-web ingestion turns on permission, licence and processing location, while enterprise documents are routed by permissions, where content may be processed, scans and quotable tables.

```mermaid
flowchart TD
  classDef stop fill:#FBE9E7,stroke:#B23A2B;
  START{"START: Is the source on the<br/>approved-source register?<br/>(owner, licence/ToS,<br/>legal basis, classification)"}
  START -- "yes" --> KIND{"What kind<br/>of source?"}
  START -- "no" ---> STOP0["STOP. Register it first.<br/>Never ingest from an unregistered source."]:::stop
  KIND --> PW["PUBLIC WEB"]
  PW --> W1{"Is this an agent fetching<br/>pages at run time?"}
  W1 -- "yes" --> W1Y["Not L8. Govern as an L4 tool call."]
  W1 -- "no" --> W2{"Does robots.txt / ToS permit it,<br/>and is the content licensed<br/>for this use?"}
  W2 -- "no" --> STOP1["STOP."]:::stop
  W2 -- "yes" --> W3["Batch ingestion into a corpus"]
  W3 --> W4{"Must processing stay in the<br/>EU/UK or in your estate?"}
  W4 -- "yes" --> W4Y["Self-host: Crawl4AI (pilot) or<br/>Firecrawl server (after AGPL review)"]
  W4 -- "no" --> W4N["Firecrawl Cloud with ZDR<br/>(+ PII redaction if any personal<br/>data may appear)"]
  W3 -- "long-tail site with an existing<br/>maintained scraper, public data only" --> APIFY["Apify"]
  KIND --> ED["ENTERPRISE DOCUMENTS"]
  ED --> E1{"Does the source carry permissions<br/>(SharePoint, OneDrive, Confluence)?"}
  ED --> E2{"May the content leave your estate<br/>(classification, client contract,<br/>residency)?"}
  ED --> E3{"Mostly scans or<br/>handwriting?"}
  ED --> E4{"Do tables feed numbers<br/>anyone will quote?"}
  E1 -- "yes" --> E1Y["Unstructured ingest connectors (ACL digest, reprocess on change), or build a connector that meets the same contract. Fail closed."]
  E2 -- "no" --> E2N["Self-hosted engine: Docling (default); MinerU only after licence review; Mistral OCR self-managed or Reducto on-prem if a commercial engine is needed"]
  E2 -- "yes, region-bound" --> E2Y{"Which region<br/>or cloud?"}
  E2Y -- "EU/UK required" --> E2Y1["Mistral OCR (EU API), LlamaParse EU,<br/>Reducto EU endpoint, Unstructured in-VPC"]
  E2Y -- "GCP is the approved cloud" --> E2Y2["Google Document AI<br/>(confirm processor region)"]
  E3 -- "yes" --> E3Y["Put an OCR engine behind the parser<br/>interface; route by confidence score"]
  E4 -- "yes" --> E4Y["Dual-parse + reconciliation; quarantine on mismatch; numbers stay non-authoritative (authoritative figures come from L4 data tools)"]
```
