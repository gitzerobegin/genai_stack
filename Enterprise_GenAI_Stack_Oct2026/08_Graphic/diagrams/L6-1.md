# L6 vector store: write path, query path and lifecycle
Caption: Content enters the store tagged with tenant and version metadata, every query is filtered by C4 entitlements inside the search rather than after ranking, and deletion, embedding model change and backup each follow a set lifecycle path.

```mermaid
flowchart TD
  classDef note fill:#FBF4E4,stroke:#D4A13A,stroke-dasharray:4 3;
  subgraph LC["LIFECYCLE [Rec]"]
    direction TB
    D1["Source delete / retraction / erasure"] --> D2["Delete by ID"]
    D2 --> D3["Compaction / vacuum"]
    M1["Embedding model change"] --> M2["Shadow index"]
    M2 --> M3["Evaluate (L9)"]
    M3 --> M4["Cut over"]
    M4 --> M5["Drop old"]
    B1["Backup = rebuild-from-source (primary)<br/>+ store snapshot (secondary)"]:::note
  end
  subgraph QY["QUERY: L3 → C4 → L6 → L7 → L3 [AJ]"]
    direction TB
    Q1["Caller identity"] --> Q2["C4 entitlements<br/>fund_ids, client_ids, max_classification"]
    Q2 --> Q3["L6: select partition(s)<br/>the caller may use"]
    Q3 --> Q4["Filter INSIDE the search<br/>never after ranking"]
    Q4 --> Q5["ANN + BM25"]
    Q5 --> Q6["Fusion: RRF / linear"]
    Q6 --> Q7["Top-N candidates + IDs"]
    Q7 --> Q8["L7 reranker"]
    Q8 --> Q9["Top-k passages + provenance"]
    Q9 --> Q10["L3 prompt assembly"]
    Q9 --> Q11["Retrieval log<br/>IDs, versions, scores"]
    Q11 --> Q12["C8 / L9"]
  end
  subgraph WR["WRITE: L8 → L7 → L6 [AJ]"]
    direction TB
    W1["Approved document"] --> W2["Chunk + metadata<br/>doc_id, version, fund_id, client_id,<br/>classification, region, retention_until,<br/>embed_model_version"]
    W2 --> W3["Dense vector<br/>+ sparse terms"]
    W3 --> W4["STORE<br/>partition = tenant: namespace / collection / schema<br/>index = ANN (HNSW / IVF / centroid / DiskANN-type) + BM25<br/>payload = text, or pointer to source of truth (L8)"]
  end
```
