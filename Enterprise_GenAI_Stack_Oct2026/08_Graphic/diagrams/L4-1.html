L4 reference flow: agents reach every tool through one governed tool gateway
%%{init: {"flowchart": {"wrappingWidth": 460}}}%%
flowchart TD
  U["Analyst / service"] -- SSO --> IDP["IdP (C4)"]
  AG["L3 agent or workflow"] --> MC["MCP client"]
  IDP -- "ID-JAG / token exchange" --> GW
  MC --> GW
  GW["TOOL GATEWAY<br/>(L4 governance, often the C1 product)<br/>1 Authenticate caller, check token audience/issuer<br/>2 Allow-list: server + tool name + definition hash<br/>3 Policy (Cedar / OPA): who, which tool, which args<br/>4 Outbound credential from vault (C7), never from the model<br/>5 Audit + OTel span (L9); DLP on outbound args (C3)"]
  GW --> T1["Internal read-only<br/>MCP servers<br/>(data, engines)"]
  GW --> T2["Calculation sandbox<br/>(microVM,<br/>egress deny)"]
  GW --> T3["SaaS apps via<br/>per-user OAuth<br/>(broker or<br/>gateway 3LO)"]
  GW --> T4["Web search / browser<br/>(egress proxy,<br/>no client data)"]
  GW --> T5["Remote agents<br/>(A2A, signed<br/>Agent Cards)"]
The user's identity reaches the tool gateway by token exchange, and the gateway authenticates the caller, checks the allow-list and policy, supplies outbound credentials from the vault rather than the model, and audits each call before it reaches internal servers, sandboxes, SaaS apps, the web or remote agents.
