# C5 prompt release: from Git change to runtime and rollback
Caption: Every prompt or configuration change goes through Git, a second approver and the L9 eval gate into one signed release manifest, and rollback is simply moving the label back to the previous version.

```mermaid
flowchart TD
  classDef note fill:#FBF4E4,stroke:#D4A13A,stroke-dasharray:4 3;
  A["Author (analyst / engineer)"] -- "edit prompt, model pin,<br/>top-k, embedding version,<br/>fallback route" --> G["Git repository<br/>(system of record)"]
  G -- "pull request" --> PR["Pull request"]
  PR --> AP["2nd approver<br/>(risk owner via CODEOWNERS)"]
  PR --> CI["CI: L9 regression + style +<br/>numeric-faithfulness evals"]
  G --> M["Release manifest vN<br/>(prompt vX, model id@date,<br/>embed model@ver, reranker@ver,<br/>k, policy vY)"]
  CI -- "pass" --> M
  M -- "signed tag" --> REG["Registry: publish vX,<br/>move protected label<br/>'production'<br/>(release identity only)"]
  M -- "signed tag" --> GW["Gateway C1:<br/>routing + fallback config"]
  M -- "signed tag" --> EV["C8 evidence:<br/>approval, eval results, diff"]
  subgraph RT["Runtime"]
    L3["L3 workflow"] --> F["Fetch label<br/>(SDK cache, code-side default)"]
    F --> LM["L1/L2 via C1"]
  end
  REG -.-> F
  F --> T["Trace (L9) carries<br/>manifest vN + prompt vX"]
  T --> RB["Rollback = move label to vN-1"]:::note
```
