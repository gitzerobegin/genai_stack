# L5 reference flow: governed write and scoped read paths for agent memory
Caption: Candidate memories must pass a policy gate before they reach the memory store and every write is logged, recall is scoped by user, fund or team and traced, and every record carries a retention class and lifecycle controls for erasure and reproducibility.

```mermaid
%%{init: {"flowchart": {"wrappingWidth": 320}}}%%
flowchart TD
  EV["Interaction events<br/>(L3 workflow, reviewer edits)"] -- "WRITE PATH (governed)" --> EX["Extraction (LLM)<br/>proposes candidate facts"]
  EX --> PG["POLICY GATE<br/>• C3 DLP: no client IDs, no special-category<br/>• type allow-list<br/>• 'no numbers as facts'<br/>• human approval for organisational memory"]
  PG --> MS["Memory store<br/>rows (SQL) · vectors (L6) ·<br/>graph edges · files/Git"]
  PG --> WL["Write log (C8)<br/>who, what, source, approval"]
  MS --> WL
  MS -- "READ PATH" --> SR["Scoped recall<br/>by user/fund/team scope (C4)<br/>+ similarity"]
  SR --> PR["Prompt"]
  SR --> TR["Trace: memory IDs +<br/>version hash (L9)"]
  MS --> LC["LIFECYCLE: retention class per record · TTL/pruner · subject index for erasure · revisions purge · snapshot per release for reproducibility"]
```
