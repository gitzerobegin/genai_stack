- Each agent offered through Cloud Marketplace needs an Agent Card aligned to the A2A Agent Card specification, stored as a JSON file in Cloud Storage.
- The agent must be discoverable through primary Google surfaces such as Gemini Enterprise, use Google or third-party models hosted in Model Garden by default, and support multi-agent interoperability through A2A.
- Agents using A2A must not include professional services, hardware or other non-software components billed through the Marketplace.
- Pricing (docs summary): free (customer pays only for Cloud resources) or flat monthly subscription.
- Listing: create the Agent Card, then build a listing in the Producer Portal and submit for review; once published, customers add the agent to Gemini Enterprise.
- Partner example: Optimizely Opal described as one of the first A2A-validated agents in Gemini Enterprise, sold through Google Cloud Marketplace.
