- "AI Agents and Tools" category in AWS Marketplace announced at AWS Summit New York City on 16 July 2025 (PYMNTS report); lists AI agents, MCP servers and A2A servers.
- Publishing requires registering as an AWS Marketplace seller through AWS Partner Central; free listings allowed.
- Delivery methods: hosted SaaS or API-based product pointing at the seller's endpoint (seller guide: create the SaaS API-based AI agent or tools product, then integrate with Marketplace APIs per the pricing model), or a container running on Amazon Bedrock AgentCore Runtime (third-party guide: ARM64 container).
- APN blog: the API-based delivery method is eligible for the SaaS Co-Sell Benefit; free trials available for API-based listings.
- Document history shows AgentCore integration instructions added for AI agents and MCP servers.
- Third-party only: an MCP server entering via AgentCore Gateway without OpenAPI needs two-legged client-credentials OAuth.
