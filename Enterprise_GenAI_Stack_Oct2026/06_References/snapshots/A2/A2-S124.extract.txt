========================================================================

All durable state stored in object storage; compute nodes stateless. Writes go to a WAL in object storage (p50 write latency 165 ms for 500kB). Tiered NVMe SSD and memory caches. Cold query p50 874 ms for 1M documents vs p50 14 ms cached. Vector index SPFresh (centroid-based). Indexing nodes separate from query nodes. Namespace isolation as prefix on object storage.
