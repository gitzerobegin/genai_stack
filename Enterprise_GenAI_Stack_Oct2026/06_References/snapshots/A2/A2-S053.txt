Developing package releases

The commits on the development branch of each version will be packaged and uploaded to 
Test PyPI
.

The package name generated by the development branch is x.y.z.rc, where  is the number of commits that differ from the most recent release.

For example, after the release of 
2.3.4
, two commits were submitted on the 2.3 branch.
The version number of the latest commit of 2.3 branch is 
2.3.5.rc2
.

For example, after the release of 
2.3.4
, 10 commits were submitted on the master branch.
The version number of the latest commit of master branch is 
2.4.0.rc10
.

To install the package on Test PyPi, you need to append 
--extra-index-url
 after pip, for example:

$

python3

-m

pip

install

--extra-index-url

https://test.pypi.org/simple/
