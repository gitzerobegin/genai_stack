Eligible customers can enable European data residency by creating a new Project in the API Platform dashboard and selecting Europe as the region. API requests initiated through these Projects will be handled in-region with zero data retention. Existing Projects cannot be updated to European data residency after creation. Enterprise privacy page (https://openai.com/enterprise-privacy/): API inputs/outputs may be retained up to 30 days; not trained on by default; AES-256 at rest, TLS 1.2+ in transit; DPA available.
