The data plane runs entirely in your cloud account within a dedicated VPC, while Pinecone manages the control plane. Pinecone does not need SSH, VPN, or inbound network access to your VPC, cluster, nodes, or workloads. BYOC supports AWS, GCP, and Azure for Enterprise users. BYOC supports dedicated read node indexes only. Billing: a flat platform fee and a rate for each dedicated read node you run, plus the customer's own cloud costs. BYOC deployments run FoundationDB inside your Kubernetes cluster to store cluster metadata. Blog: https://www.pinecone.io/blog/byoc/ 'Pinecone BYOC: Pinecone in your AWS, GCP, or Azure account, no vendor access'.
