========================================================================

S3 Vectors: storage $0.06 per GB per month; PUT $0.20 per logical GB uploaded (each vector = logical vector data + metadata + key), minimum charge of 128KB per PUT; query request fee $2.50 per million queries; data processed tiered $0.004/TB for the first 100K vectors, $0.002/TB for 100K-10M vectors, $0.0004/TB for 10M+ vectors; data returned $0.01/GB; first 512KB returned per query free. Worked example: 59 GB storage $3.54/month; total $11.38 per month; another example 50-million-vector index, 4.1 KB per vector, 1 million queries returning 10,000 results each totals $178.61 per month. (Rates as shown in the US region example; region variation not captured.)
