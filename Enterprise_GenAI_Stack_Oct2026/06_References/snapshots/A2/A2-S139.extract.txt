Atlas data encrypted at rest with AES-256 by default. Customer key management with AWS KMS, Azure Key Vault, Google Cloud KMS (not for Free or Flex clusters). Customer-managed encryption does not apply to search indexes in default architecture; with dedicated Search Nodes, Search Node Data Encryption encrypts search indexes with the same customer-managed keys; enabling CMK rebuilds Search and Vector Search indexes.
