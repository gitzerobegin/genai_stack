By default, all new vectors in S3 Vectors vector buckets use SSE-S3. SSE-KMS can be set at bucket level or per index; index inherits bucket encryption if not specified; encryption settings for a vector index can't be changed after creation. Encryption applies to vector data and all associated metadata. KMS keys must be specified by full ARN. Service principal indexing.s3vectors.amazonaws.com needs kms:Decrypt. CMKs allow monitoring key usage through AWS CloudTrail. HIPAA eligibility of S3 Vectors not confirmed by the search tool.
