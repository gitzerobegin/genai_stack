- Privacy Mode: Teams and Enterprise admins can enforce it organisation-wide so members cannot disable it. Privacy Mode does not suppress audit events; audit payloads carry identifiers and setting values rather than prompts or generated code.
- SCIM provisioning is an Enterprise feature. Admins can enforce SSO, disable local login and provision/deprovision users with SCIM.
- Audit logs are Enterprise-only: authentication, team/membership changes, API key actions, privacy-mode and settings changes; filterable by application, CSV export; stream to SIEM, webhooks or S3. The Admin API appears as an application type in the log.
