Search-tool summary of copilot.github.trust.page and its FAQ (copilot.github.trust.page/faq):
- The Trust Center lists ISO/IEC 42001:2023 among its compliance items, with a 2026 certificate, and a SOC 2 Type 2 report for GitHub Enterprise Cloud and Copilot. Listed compliance items include SOC 1, SOC 2, SOC 3, ISO 27001:2013, CSA STAR Level 2, TISAX and ISO/IEC 42001:2023.
- The FAQ is older and describes a narrower SOC 2 scope: GitHub published a SOC 2 Type I report for Copilot Business (2024).
- IP indemnification (FAQ): Copilot Business and Enterprise customers are entitled to IP indemnification for responses provided by Copilot. Two options for most features: set the duplicate detection filter ("Suggestions matching public code") to Block; or keep it on Allow, where Copilot provides details of the code an output matches, and if you comply with any cited licences in the matching code you remain eligible for IP indemnity. The "Suggestions matching public code" filter does not apply to the Copilot coding agent.
