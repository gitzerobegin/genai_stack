AWS What's New (2026/03): "Policy in Amazon Bedrock AgentCore is now generally available" - centralized, fine-grained controls for agent-tool interactions; available in thirteen AWS Regions (AgentCore overall in fifteen per FAQ). Natural language input automatically converts to Cedar. AWS blog: Cedar "an open source authorization policy language developed by AWS that has recently joined the Cloud Native Computing Foundation (CNCF)". Policies attached to a Gateway block everything by default. Preview December 2025.
Current documentation: policies are authored in Dogwood; the authoring guide describes Dogwood as an open source policy language compatible with Cedar that adds conditions Cedar cannot express; every valid Cedar policy is also a valid Dogwood policy. FAQ: Dogwood "a new open source governance language purpose-built for AI agents".
