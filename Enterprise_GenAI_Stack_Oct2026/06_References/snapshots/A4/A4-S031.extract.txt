========================================================================

LangChain changelog entry dated October 14, 2025: LangGraph Platform has been renamed to LangSmith Deployment as of October 2025; LangGraph Studio is now LangSmith Studio. LangSmith has 3 services: LangSmith Observability, LangSmith Evaluation, and LangSmith Deployment. LangGraph remains the open-source framework, while LangSmith Deployment is the managed service for running agents. Support docs describe the product as graph runtime and deployments, previously called LangGraph Platform.
