Sessions: a persistent memory layer for maintaining working context within an agent loop; best default for durable memory, resumable approval flows, or storage your application controls. Handoffs: when a handoff occurs, the delegated agent receives the conversation history and takes over; manager-style alternative where a central agent calls sub-agents as tools. Guardrails run checks/validations on user input in parallel to the agent and on the agent's output; separate input and output guardrails. Tracing on by default (handoff_span, guardrail_span); can be disabled globally/per run or sent to custom trace processors. Running Agents docs list a Temporal integration "to run durable, long-running workflows, including human-in-the-loop tasks", and other durable options including DBOS.
