Enterprise customers can set up SAML 2.0 SSO; SAML or OIDC with just-in-time (JIT) provisioning. Self-hosted supports SSO with OAuth2.0 and OIDC. SCIM requires an Enterprise plan, an IdP that supports SCIM 2.0, and an Organization Admin. Enterprise RBAC lets you define permissions per workspace using built-in or custom roles. Self-hosted changelog: audit logging introduced in self-hosted v0.12.33; enabled by default in v0.13.37; in v0.14 Attribute-Based Access Control and audit logs are enabled by default for self-hosted deployments (GA). Logged events include API key management, user and role changes, SSO configuration changes, workspace operations and resource management including deployments; logs stored in OCSF 1.7.0 format, compatible with SIEM tools like Splunk and Datadog.
