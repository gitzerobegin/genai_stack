Search tool summary:
- Europe: eligible customers create a new API Project with Europe region; requests handled in-region with zero data retention. Developer docs list eu.api.openai.com supporting storage and processing; requires MAM (Modified Abuse Monitoring) or ZDR approval. Regional processing per request via regional domain prefix.
- UK: OpenAI announced UK data residency (Friday 24th October) to store data in the UK. gb.api.openai.com is storage-only; processing not supported for UK; requires MAM or ZDR.
- ZDR: OpenAI does not retain prompts or responses after processing; requires prior approval. Without it, OpenAI may retain API inputs and outputs for up to 30 days for service and abuse monitoring. Some endpoints (conversations, assistants, threads, vector stores, files, fine-tuning jobs) are not ZDR-eligible.
- Training: By default, OpenAI does not use data from ChatGPT Enterprise, Business, Edu, ... or our API platform, including inputs or outputs, for training.
- CSAM-flagged images retained even under ZDR.
- Private Safety Processing option in rollout. NYT litigation preservation order does not impact ZDR API customers.
- DPA available; Trust Portal holds GDPR/DPA/subprocessor documents.
