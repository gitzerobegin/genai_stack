Admin and Audit Logs API for the API Platform (help.openai.com), with developers.openai.com Admin APIs guide and changelog, as summarised by the search tool:
- Admin API manages invitations, users, projects, project memberships, service accounts, API keys and admin keys; only organization owners can create organization admin keys.
- Audit logs record administrative and configuration events (API key changes, invitations, user and service-account lifecycle, failed logins and logouts, organization setting updates, project changes). They do not include the content of API requests and responses.
- An owner enables audit logging under organization settings (Data controls > Data retention); once enabled it can only be turned off via OpenAI Support.
- Endpoint GET /organization/audit_logs.
- No fixed retention period for audit logs; kept on a best-effort basis; organizations with retention or eDiscovery requirements should export copies. ZDR does not change audit-log availability.
- Admin and Audit Log APIs launched August 2024; May 2026 update added Admin API support for spend alerts, model allowlists, data retention settings and billing line items.
