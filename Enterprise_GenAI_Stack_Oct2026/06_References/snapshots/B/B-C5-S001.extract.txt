- LaunchDarkly implements SSO with the SAML 2.0 protocol; the IdP can manage member login and member roles, or login only (guide "Using SSO with LaunchDarkly"; "Configure SAML SSO").
- IdP-specific guides: Okta, Entra ID, Google Workspace, OneLogin, ADFS. Entra Security Groups can be assigned LaunchDarkly custom roles.
- Custom roles are assigned via a customRole SAML attribute (list of role keys, case-sensitive); custom roles supersede the base role.
- "Custom roles is an Enterprise feature." Custom Roles API exists (launchdarkly.com/docs/api/custom-roles).
