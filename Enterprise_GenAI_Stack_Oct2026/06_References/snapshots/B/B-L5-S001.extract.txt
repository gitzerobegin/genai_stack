OWASP GenAI Security Project article "Memory Is a Feature. It Is Also an Attack Surface" (13 May 2026), as reported by the search tool:
- ASI06 in the OWASP Top 10 for Agentic Applications (released December 2025) covers memory and context poisoning.
- The entry's co-lead (Idan Habler, Cisco) describes the risk as agents carrying untrusted input forward instead of handling it once and discarding it: attacker-controlled content poisons memory and context that the system continues to trust over time, so the system may continue treating attacker-controlled content as legitimate guidance.
- Persistence is the concern: corrupted context remains available, continues to circulate and can shape future planning, tool use and behaviour.
- The Agentic Top 10 describes memory poisoning as reshaping behaviour long after the initial interaction.
Related: OWASP Agent Memory Guard project page (https://owasp.org/www-project-agent-memory-guard/) presents itself as a reference implementation for ASI06 (integrity hashing of memory, policy on memory reads/writes, snapshots and rollback) - project's own description, not an official OWASP mitigation list.
