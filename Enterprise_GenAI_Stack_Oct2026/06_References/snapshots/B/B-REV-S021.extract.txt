Braintrust docs "Audit logging" page (found on a braintrust.dev preview domain; structure matches the main docs site, confirm against production docs), as summarised by the search tool:
- Audit logs record administrative actions (creating projects, changing settings, granting permissions, managing members, creating API keys); recorded only while the organisation is on an Enterprise plan.
- Owners can read them by default; others need the organisation-level "Read audit logs" permission.
- Queryable with SQL via the audit_logs() data source (SQL sandbox, bt sql CLI or API).
- Retained for the life of the Enterprise subscription, outside the plan's normal retention window.
