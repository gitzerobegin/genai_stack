Mistral docs "Audit logs" overview, as summarised by the search tool:
- Audit logs are an Enterprise feature, enabled by default for all Workspaces, opened from Admin Panel > Administration > Audit Logs.
- Each entry records timestamp, actor (human user, API key or system), event, target resource and metadata.
- Logged activity includes sign-ins and SSO flows, API key creation and deletion, organization and Workspace changes, invitations and role changes, settings modifications.
- Log export is not supported.
