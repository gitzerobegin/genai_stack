Azure Database for PostgreSQL flexible server: extension 'vector' must be allowlisted then CREATE EXTENSION; IVFFlat, HNSW and DiskANN (DiskANN Azure-only); vectors over 2,000 dimensions stored but not indexed; release notes (May 2025) list pgvector 0.8.0; Azure maintains extension versions (customers cannot update/downgrade).
Cloud SQL for PostgreSQL (https://docs.cloud.google.com/sql/docs/postgres/generate-manage-vector-embeddings): pgvector supported; PostgreSQL 13+ supports pgvector 0.8.5; release notes 27 August 2026 record upgrade 0.8.1 to 0.8.5.
AlloyDB (https://docs.cloud.google.com/alloydb/docs/ai/vector-search-overview): uses a customised pgvector extension ('vector'); HNSW plus ScaNN index (alloydb_scann).
