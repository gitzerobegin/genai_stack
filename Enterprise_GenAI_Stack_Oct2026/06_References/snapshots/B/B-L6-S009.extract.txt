Weaviate RBAC: predefined root and viewer roles; custom roles from permissions assigned to users. Authentication (https://docs.weaviate.io/deploy/configuration/authentication): API keys and OIDC (any issuer implementing OpenID Connect Discovery), both can be enabled; OIDC users and groups can hold roles. Logging (https://docs.weaviate.io/deploy/configuration/logging): RBAC audit logging automatic when RBAC enabled (successful authorisations at info, denials at error; user, action, decision, source IP, resource); role creation/deletion logged. Note in docs: "RBAC access will be available in WCD in a future release" (Weaviate Cloud console).
