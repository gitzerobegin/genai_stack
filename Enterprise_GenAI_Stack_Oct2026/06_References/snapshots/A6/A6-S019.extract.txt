Extract as returned by search tool:
- The core features are free. Per Cloudflare's pricing page, core features include dashboard analytics, caching, and rate limiting. "some new features may be additional core features that will be free while others may be part of a premium plan."
- Log storage: Customers whose first gateway was created on or after September 24, 2026 follow Workers Logs pricing and retention. Older gateways use Legacy Logs, with a 100,000-log total limit on Workers Free and 10,000,000 logs per gateway on Workers Paid.
- Guardrails run prompts and responses through a Llama Guard model on Workers AI. Usage is billed as Workers AI token-based inference. You can choose whether to moderate prompts, responses, or both, and whether flagged content is blocked or only flagged.
- DLP scanning is free on all plans. Accounts without a Zero Trust subscription get only two predefined profiles: Financial Information and Social/Insurance/National Identifier Numbers. A Zero Trust subscription that includes DLP unlocks the full set of profiles, including custom ones.
- Dynamic Routing: create request routing flows without code changes, based on user segments, geography, content analysis, or A/B tests. For failing across different providers, use Dynamic Routing. Auto Router routes each request to the most cost-effective model that can handle the task.
- Unified Billing: "A 5% fee is applied to all credits purchased through Unified Billing." Provider inference is not marked up. Starting with September 1, 2026 invoices, monthly usage invoices show a single total cost for each model.
- Spend limits are cost-based budgets that block requests once the budget is exceeded, scoped by model, provider, or custom metadata; a June 2026 post says spend limits are available now for all users. Identity-based controls followed in August, using Cloudflare Access identity for per-user budgets.
