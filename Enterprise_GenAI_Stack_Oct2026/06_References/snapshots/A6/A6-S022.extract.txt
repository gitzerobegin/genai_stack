It is a reference architecture built on the open-source LiteLLM project. Organizations can use it to integrate with AI providers while keeping centralized control, security, and observability.
Deployment is handled through CloudFormation and AWS CDK templates for automated deployment into an Amazon ECS cluster. The Guidance can also run on EKS.
Requests reach the gateway through Route 53 or CloudFront, with AWS WAF in front of an Application Load Balancer. Models hosted on Amazon Bedrock provide model access, guardrails, prompt caching, and routing through a unified API.
The gateway distributes requests across multiple model deployments and fails over to backup providers when issues are detected, with retry and exponential back-off.
The resilience post describes distributing requests across Regions through CRIS (cross-region inference), using multiple AWS accounts.
None of the results describe Bedrock Intelligent Prompt Routing being wired into the Guidance.
