AgentCore Gateway's MCP support has been generally available since the October 2025 AgentCore GA release. "AgentCore Gateway now connects to existing Model Context Protocol (MCP) servers in addition to transforming APIs and Lambda functions into agent-compatible tools."
"AgentCore Gateway supports the following MCP versions: 2026-07-28, 2025-11-25, 2025-06-18, and 2025-03-26."
Gateway pricing: "Gateway · API Invocations (e.g. ListTools, InvokeTool, Ping) · $0.005 per 1,000 invocations; Gateway · Search API · $0.025 per 1,000 invocations; Gateway · Tool Indexing · $0.02 per 100 tools indexed per month". "Data egress to customer-owned VPCs is charged a data processing rate of $0.006 per GB in commercial AWS Regions".
Identity pricing: Identity is free when reached through Runtime or Gateway. "Identity · Token or API key requests for non-AWS resources · $0.010 per 1,000 token or API keys requested by the agent".
Policy pricing: "Policy · Authorization Request · $0.000025 per request Your first 100 temporal policies per policy engine incur no additional authorization charges; Policy · Input Tokens Processed · $0.13 per 1,000 tokens".
