Cross App Access (XAA) is generally available, and ships through two Okta products: Agent SSO, which is included in core SSO, and Okta for AI Agents, which is a separate subscription.
Agent SSO: Okta announced its general availability on August 24, 2026, "included in core Okta SSO at no additional cost. Okta for AI Agents is available as a separate subscription." Okta's support documentation describes Agent SSO as Generally Available and included in core workforce SSO plans. (One Okta press release says GA since May 2026 - dates conflict.)
XAA: "an open, vendor-neutral protocol that allows identity security to follow agents dynamically across applications"; it "extends OAuth and is formally incorporated as the official Enterprise-Managed Authorization extension for the Model Context Protocol". Release notes say XAA removes the need for user consent at runtime. Help docs: all Okta orgs can use Cross App Access (XAA).
Integration network support: Anthropic (Claude), Archestra.AI, Asana, Atlassian, Canva, Datadog, Figma, Glean, Granola, Linear, MintMCP, Notion, Slack, Supabase.
Oktane 2026: Agent Gateway and Shadow AI Agent Discovery for Endpoints planned to be GA in Q3 (not confirmed).
