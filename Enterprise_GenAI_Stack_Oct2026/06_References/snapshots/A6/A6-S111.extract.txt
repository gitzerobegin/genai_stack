NeMo Guardrails is available both as an open-source toolkit and as a microservice. The microservice NGC Helm chart page is tagged "NVIDIA AI Enterprise Supported" and requires sign-in for download.
Per NVIDIA's 25.11.0 docs, certain toolkit server features are unavailable in the microservice, such as threads and the chat user interface. "The microservice supports Colang 1.0 guardrail configurations only." It supports NIM for LLMs and LLMs hosted on an OpenAI-compatible API endpoint.
Safety NIMs: content safety (docs: checks against 23 categories; a tutorial says 42 hazard categories - conflict), topic control, jailbreak detection. The microservice places NemoGuard NIM microservices between the application and its LLM.
