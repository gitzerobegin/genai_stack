"Updated on March 3, 2026 – Policy in Amazon Bedrock AgentCore is now generally available." It launched in preview in December 2025. At GA, AWS listed thirteen AWS Regions, including US East (N. Virginia), Europe (Ireland), and Asia Pacific (Tokyo). A later AWS update says Policy also arrived in AWS GovCloud (US-West) with memory and harness features.
You can write rules in plain English, and the service converts them to Cedar, AWS's open-source policy language. Cedar is also available for direct editing. An LLM drafts the Cedar policy, then AgentCore Policy uses a Cedar schema generator that takes the MCP tool descriptions and produces a Cedar schema; Cedar Analysis encodes each policy as a mathematical formula and detects issues like policies that grant or deny everything.
A policy engine is attached to a Gateway, and the Gateway evaluates each agent-to-tool request before the tool runs. "When you associate a Policy with a Gateway, it blocks everything by default." Cedar policies can use the caller's identity claims as well as the tool's input arguments.
Tool filtering: "When an agent issues a list tools command, AgentCore Gateway uses Cedar's partial evaluation capability to determine which actions would always be denied under the current policy set. Those actions are omitted from the list tool response."
Cedar uses default deny, and a forbid overrides a permit. Enforcement decisions logged through CloudWatch metrics and logs.
Cedar cannot make external lookups, such as fetching data from DynamoDB, so those cases need a Lambda interceptor alongside the policy.
