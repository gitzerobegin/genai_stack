Product page title "Content Safety in Foundry Control Plane": "Learn how you can use Content Safety to build generative AI guardrails in Microsoft Foundry."
A Microsoft Q&A answer says the two are not the same product, but "Guardrails explicitly builds on Azure AI Content Safety models". Content Safety still offers capabilities that guardrails don't expose (Image Moderation, Multimodal, Custom Categories).
Content filters refer to Microsoft Foundry Models (classic); the newer model uses guardrails; "A guardrail is a named collection of controls." By default, models are assigned the Microsoft.DefaultV2 guardrail, which can't be edited.
The guardrail system currently applies only to agents developed in the Foundry Agent Service, not to other agents registered in the Foundry Control Plane. Inspection points: user input, output, tool calls (preview), and tool responses (preview). For agents, the agent's guardrail overrides the model's guardrail.
