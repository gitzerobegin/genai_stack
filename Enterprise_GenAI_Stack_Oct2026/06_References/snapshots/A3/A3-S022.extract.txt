Search-tool summary of CSA research notes: A CSA note says several high-severity vulnerabilities from mid-2025 to June 2026 affected Cursor, Claude Code, Gemini CLI, GitHub Copilot, and Amazon Q. The issue is that these IDEs launch project-defined MCP servers with developer-level privileges and no process isolation. Because the agent can read files, run shell commands, and access cloud credentials, one poisoned repository configuration can affect every developer who clones it (a poisoned repository configuration that reaches multiple developers multiplies the impact proportionally). Microsoft's security team reportedly disclosed on June 30, 2026 that tool descriptions can be altered so an agent gathers and exfiltrates data while every individual action looks authorized. Its proof of concept used a harmless-looking calculator tool with hidden text that told the agent to read an SSH private key and smuggle it out as a tool parameter. Against Cursor, the user saw only a truncated summary. Attribution is unclear: another CSA snippet dates a near-identical calculator-and-SSH-key proof of concept against Cursor to April 2025. A CSA table lists the main categories: Tool description poisoning hides instructions in metadata; Rug pulls change a tool's definition on the server after a user has approved it; Tool shadowing has a malicious description steer the agent toward other, legitimate tools, enabling cross-server exfiltration; Supply-chain compromise distributes malicious packages through public registries or updates. OWASP lists tool poisoning as MCP03:2025 in its MCP Top 10. Suggested mitigations include patching affected IDEs, allowlisting installed MCP servers, and treating any change to an MCP config file as a code-review event.
