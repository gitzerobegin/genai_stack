Search-tool summary of the AAIF project proposal (GitHub issue #47 in aaif/project-proposals, dated as of September 2026): The spec is currently a living document; spec changes are merged on GitHub without a written approval rule. The roadmap calls for moving from a living document to tagged releases with a changelog, so implementers can declare and test against a specific version. Current state: decisions rest with the leadership team, and there is no separate steering body. The listed maintainers are Anthropic employees. Planned: the project would operate under the Technical Charter and a published GOVERNANCE.md defining maintainer roles and the spec-change approval rule; GOVERNANCE.md and MAINTAINERS.md to be published during onboarding. A Technical Steering Committee would start with engineers from organizations that ship production implementations joining Anthropic's maintainers, with composition and decision rules to be settled with the Linux Foundation during onboarding. This is a proposal (intended future state), not confirmed policy; acceptance status not found.
