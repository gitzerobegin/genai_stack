Search-tool summary: 'Short-term memory captures raw events (messages, tool calls) within a session. ... Long-term memory extracts durable knowledge via configurable strategies (semantic, summarization, user preference, episodic, or custom) and makes them retrievable via semantic search in later sessions.' Semantic strategy uses vector embeddings for similarity search; Summary creates running narratives; User preference extracts behaviour patterns; Episodic captures goal, steps, outcomes, reflections, scoped to session; Custom uses own foundation model and prompt templates. Namespaces group records (e.g. actor-level). Event expiry on the memory resource controls retention of raw short-term events; UpdateMemory reference gives 7-365 days but also lists a minimum value of 3 (conflict). Lifecycle guide: AgentCore memory 'doesn't provide a built-in auto-delete TTL for records'; exposes timestamp fields supporting BEFORE/AFTER filters on ListMemoryRecords; suggests 30-60 days for summaries, 6-12 months for semantic memories; 'TTL ... is essential for compliance.' DeleteMemoryRecord removes a single record; BatchDeleteMemoryRecords; consolidation can delete/supersede; per-user erasure sample lists every record in that user's namespace and deletes them individually. Deleting the memory resource permanently removes all events and records. 'Managed memory cannot be deleted directly through the Memory APIs' (harness). Memory record streaming emits MemoryRecordDeleted events. Aug 2026: AgentCore Memory supports extracting memories from non-conversational JSON payloads (aws.amazon.com/about-aws/whats-new/2026/08/agentcore-memory-json-payloads/).
