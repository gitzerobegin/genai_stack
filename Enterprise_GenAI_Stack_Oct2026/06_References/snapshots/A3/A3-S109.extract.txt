Search-tool summary of docs.cloud.google.com Memory Bank pages and release notes: 'It uses LLM-based extraction of memories from conversation history, and memories are generated remotely and asynchronously so the agent doesn't need to wait. Retrieval is similarity search-based and scoped to an identity.' 'Memory Bank extracts memories from source data and self-curates memories for a specific collection of memories (defined by a scope) by adding, updating, and removing memories over time.' Scope is defined when the memory is generated or created and is immutable; only memories with exactly the same scope are returned. TTL configuration 'Defaults to no TTL'; when a memory expires it is not available for retrieval and will be deleted; updates reset expiration; memory revisions default TTL 365 days. Delete by resource name; bulk purge by filter (e.g. all memories for user_id '123') with dry-run (force=False). A memory may be deleted if new information contradicts it or if the content instructs Memory Bank to forget a subject (EXPLICIT_INSTRUCTIONS topic). 'Deleting your Agent Runtime instance will also delete your memories if you're using built-in Memory Bank.'
